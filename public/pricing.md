# CommitDiary pricing

CommitDiary has a local starting point and optional hosted features.

## Local

- Price: free to start
- Includes: VS Code extension, Git commit discovery, local journal, offline queue, and no card required
- Best for: developers who want a private work journal in the editor

## Hosted plans

Paid hosted plans can add authenticated cloud sync, hosted history, engineering reports, sharing, and Discord delivery. The available plan names, prices, currencies, limits, and checkout availability are served by the current billing catalog and shown at:

https://commitdiary.dev/#pricing

The catalog is the source of truth. Final currency, tax, and checkout details are shown by Paddle when checkout is available. Do not infer a paid plan’s current availability from this static document.
